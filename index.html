01

开机黑屏、风扇在转但显示器无信号，怎么排查？

绝大多数开机黑屏来自内存接触不良、显卡输出或外设冲突，按顺序排除即可。

硬件故障高频问题

按顺序排查，大多数问题在第三步内解决

  1. 最小化启动：拔掉所有外设（鼠标键盘外的 U 盘、硬盘、扩展坞），只保留电源线、显示器和主机，再开机。
  2. 重插内存条：断电后取下内存条，用干橡皮擦拭金手指，重新插紧；有两条内存时先只插一条，并更换插槽测试。
  3. 检查显示输出：确认显示器信号线插在显卡上（而非主板核显口），换一根线或换一个接口；有独立显卡可先拔掉独显、用核显输出。
  4. 清除 CMOS：断电后取下主板纽扣电池 30 秒再装回，恢复默认 BIOS 设置。
  5. 以上无效时，用主板蜂鸣器或 Debug 灯判断故障位置（内存、显卡、CPU 各自对应的灯/响声）。

提示

开机自检灯亮到一半停住、或风扇转一下即停，通常是供电或主板问题，需重点检查电源插头和 24pin/8pin 是否插紧。

02

开机蓝屏 0x0000007B（INACCESSIBLE_BOOT_DEVICE）怎么解决？

这个代码指向系统无法读取启动硬盘，多见于硬盘模式设置或系统迁移后。

硬件故障
  1. 检查硬盘模式：开机进 BIOS，找到 SATA/存储设置，在 AHCI 与 RAID/IDE 之间切换（系统安装时用的是哪种，启动时就必须一致），保存重启。
  2. 确认硬盘被识别：进 BIOS 查看是否能看到系统盘；看不到则检查 SATA/M.2 接口是否插紧，或换一个接口测试。
  3. 修复引导：用系统安装 U 盘进入修复模式，运行启动修复；或打开命令提示符执行： bootrec /fixmbr bootrec /fixboot bootrec /rebuildbcd
  4. 刚迁移过系统（如换了主板或硬盘克隆）出现此代码，优先检查模式与引导，通常不需要重装。
03

电脑越来越卡顿，先查什么、怎么解决？

先看资源占用找到元凶，再清理启动项，硬件太旧时优先换固态硬盘。

系统问题高频问题

第一步：定位占用大户

按 Ctrl + Shift + Esc 打开任务管理器，按 CPU、内存、磁盘列排序，找到长期 100% 的进程。常见元凶：浏览器标签过多、后台更新、杀毒软件全盘扫描、挖矿/捆绑软件。

第二步：清理开机启动项

任务管理器 →「启动应用」，禁用不需要自启的程序（如各类管家、播放器、网盘）。

第三步：检查磁盘

  • 系统盘剩余空间最好保持在 15% 以上，不足时先做 C 盘清理。
  • 用 CrystalDiskInfo 查看硬盘健康度，机械盘出现 C5/C6 警告需尽快备份。

硬件层面

机械硬盘换 SSD 是提升最明显的单项升级；内存不足 8GB 时加内存。两者都能让老电脑"复活"。

04

C 盘空间不足怎么清理？分步操作

从系统自带清理开始，再到迁移用户文件夹，最后考虑扩展分区。

系统问题
  1. 磁盘清理：右键 C 盘 → 属性 → 磁盘清理 →「清理系统文件」，勾选 Windows 更新清理、临时文件、回收站。
  2. 清理用户临时目录：Win + R 输入 %temp% 与 temp，全选删除可删文件（占用中会自动跳过）。
  3. 迁移用户文件夹：把「桌面 / 下载 / 文档 / 视频」右键 → 属性 → 位置 → 移动到 D 盘等大分区，腾出大量空间。
  4. 关闭或缩减休眠文件：管理员运行命令提示符执行 powercfg /h off（会关闭快速启动，酌情使用）。
  5. 扩展分区：磁盘管理里若 C 盘后有未分配空间，右键 C 盘 →「扩展卷」；相邻分区可先用分区工具收缩腾出空间。
05

电脑连不上 Wi-Fi 怎么办？

先区分是"连不上"还是"连上没网"，再按软件到硬件的顺序排查。

网络连接
  1. 重启三件套：重启电脑、重启路由器/光猫（断电 30 秒再开）。
  2. 忘记网络重连：设置 → 网络 → WLAN → 管理已知网络，删除当前 Wi-Fi 后重新连接并输入密码。
  3. 释放并续租 IP：管理员运行命令提示符： ipconfig /release ipconfig /renew
  4. 检查无线网卡：任务管理器 → 网络适配器，确认无线网卡未被禁用；有黄色感叹号则到官网重装驱动。
  5. 排查路由器：其他设备能否连上？若只有这台电脑不行，试连接手机热点，能连则问题在路由器设置（如 MAC 过滤、频段限制）。
06

网速慢、频繁掉线，怎么定位是宽带、路由还是电脑？

用排除法分层测试：先测有线，再看无线频段，最后查 DNS 与路由器设置。

网络连接
  1. 有线测速做基准：用网线直连路由器测速。有线也慢 → 问题在宽带或光猫，报修运营商；有线正常 → 问题在无线环境。
  2. 频段选择：5GHz 快但穿墙差、2.4GHz 覆盖好但易受干扰。离路由器远就切 2.4GHz，近则用 5GHz。
  3. 更换 DNS：部分运营商 DNS 解析慢。在网络适配器属性里改用公共 DNS（如 223.5.5.5、119.29.29.29）。
  4. 调整路由器信道：登录路由器后台，把无线信道从「自动」改为 1/6/11（2.4G）或较空闲的 5G 信道，减少邻居干扰。
  5. 检查发热与老化：路由器长时间高负载会过热断流，摸外壳过热就垫高散热；用了多年的路由器可考虑更换 Wi-Fi 6 设备。
07

软件闪退、提示缺少 DLL 或运行库，怎么处理？

多数"缺 DLL"不是文件丢了，而是运行库没装齐，按顺序补齐即可。

软件应用
  1. 重装该软件：卸载后从官网重新下载安装，安装时右键「以管理员身份运行」。
  2. 补齐运行库：安装 Microsoft Visual C++ 运行库合集（2015-2022 x86/x64 都装）、.NET Desktop Runtime，游戏类还需 DirectX 修复工具。
  3. 系统文件检查：管理员运行命令提示符执行 sfc /scannow，修复损坏的系统文件。
  4. 兼容模式：右键程序 → 属性 → 兼容性 → 以 Windows 7/8 兼容模式运行，适用于老软件。
  5. 从非官网渠道下载的软件闪退，先杀毒扫描，可能是被杀毒拦截或文件不完整。
08

桌面弹广告、浏览器主页被改，疑似中病毒怎么办？

先断网隔离，再查启动项与计划任务，最后用安全模式彻底清理。

软件应用
  1. 断网 + 全盘杀毒：立即断开网络，用 Windows Defender 或正规杀毒软件做一次完整扫描。
  2. 清理可疑启动项与计划任务：任务管理器「启动」里禁用不认识的项目；taskschd.msc 检查计划任务库里是否有陌生定时任务。
  3. 重置浏览器：浏览器设置里恢复默认主页/搜索引擎，检查扩展列表，卸载可疑插件。
  4. 安全模式复查：按住 Shift 重启 → 疑难解答 → 启动设置 → 进入安全模式，在干净环境里再扫一遍。
  5. 治本：回想最近装过什么"全家桶"软件，卸载并清注册表残留；以后只从官网下载，安装时取消勾选捆绑项。
09

驱动装不上、设备管理器里有黄色感叹号，怎么处理？

先卸载旧驱动再装新的，优先从硬件厂商官网下载对应版本。

驱动外设
  1. 看错误码：设备管理器 → 右键感叹号设备 → 属性，记下错误代码（如 43、56、10），不同代码对应不同原因。
  2. 彻底卸载再装：右键设备 →「卸载设备」并勾选「删除此设备的驱动程序软件」，重启后再安装新驱动。
  3. 去官网下载：显卡去 NVIDIA/AMD/Intel 官网，笔记本去品牌官网按机型下载；避免用第三方"驱动大师"类工具。
  4. 回滚驱动：如果是更新驱动后才出问题，属性 →「驱动程序」→「回退驱动程序」。
  5. 新装系统后网卡驱动缺失导致没网，可先用手机 USB 共享网络下载驱动，或从另一台电脑拷贝离线安装包。
10

打印机或 USB 外设连不上、电脑不识别，怎么排查？

先换口换线排除硬件，再检查系统服务与驱动，最后重装设备。

驱动外设
  1. 换接口换线：把 USB 设备插到机箱背面接口（供电更稳），更换一根数据线；U 盘类设备可先在其他电脑确认是否损坏。
  2. 检查打印机服务：Win + R 输入 services.msc，确认 Print Spooler（打印后台服务）状态为"正在运行"，未运行则右键启动。
  3. 设为默认打印机：设置 → 蓝牙和其他设备 → 打印机和扫描仪，把目标打印机设为默认；连接网络打印机需在同一局域网。
  4. 重装驱动：卸载设备后从品牌官网下载对应型号驱动重装，重启电脑。
  5. USB 供电不足：多个高功耗设备同时连接时，用带独立供电的 USB 集线器。
11

怎么给电脑加装固态硬盘（SSD）并迁移系统？

先确认主板接口类型，装好后用克隆或重装两种方式把系统搬到 SSD。

装机升级高频问题
  1. 确认接口：查主板型号支持 M.2（NVMe）还是 SATA 接口。M.2 速度快但需确认是 NVMe 协议；老主板多为 SATA 2.5 英寸盘。
  2. 安装：断电开箱，M.2 斜插后拧紧螺丝；SATA 盘接数据线和电源线。装好后进 BIOS 确认新盘被识别。
  3. 迁移系统（免重装）：用官方或第三方克隆工具（如傲梅分区助手、DiskGenius 的"系统迁移"功能）把 C 盘克隆到 SSD，注意目标盘空间要大于已用空间。
  4. 设置启动顺序：进 BIOS 把 SSD 设为第一启动项；建议迁移后先断开旧盘测试能否正常开机，再格式化旧盘。
  5. 检查 4K 对齐：系统自带 msinfo32 或工具查看分区偏移，克隆工具一般会自动对齐；未对齐会影响性能与寿命。
12

内存条怎么选、怎么加装？

代数、频率、双通道三个关键词，选对插槽顺序就能安全升级。

装机升级
  1. 先查代数：用 CPU-Z 查看内存类型——DDR3、DDR4 还是 DDR5，必须买同代内存，物理上也不兼容。
  2. 频率与容量：新内存频率建议与旧条一致或相近（主板会自动降到较低频率）；容量按需求选，日常 16GB 起步，剪辑/虚拟机可上 32GB。
  3. 双通道：两条内存插在「相同颜色」或主板标注的 A2/B2 插槽（通常隔一个插），组成双通道带宽翻倍。
  4. 品牌兼容：不同品牌内存混插大多能跑，但为稳妥可买同品牌同型号；插上后进 BIOS 确认识别容量与频率。
  5. 散热与电源：带散热马甲的内存条注意机箱风道；内存功耗极低，一般无需升级电源。

FAQ

常见问题速览

几条最常被问到的问题，简短回答见下；想深入讨论可到评论区。

电脑开不了机、黑屏怎么办？

先做最小化排查：断开所有外设，只留电源和显示器；重新插拔内存条并用橡皮擦拭金手指；检查显示器信号线连接；仍黑屏则拔掉独立显卡用核显输出，或更换内存插槽。逐项排除可定位大多数开机黑屏故障。

电脑蓝屏错误代码怎么看？

蓝屏界面会显示 STOP 错误代码（如 0x0000007B）。记录代码后优先排查：最近是否安装过驱动或软件、内存与硬盘是否异常、系统文件是否损坏。可用事件查看器或蓝屏分析工具定位具体驱动。

C 盘空间不足怎么清理？

依次操作：磁盘清理（含系统文件）、清理临时文件夹与回收站、将桌面/下载/文档等用户文件夹迁移到其他盘、检查并清理休眠文件，最后可用磁盘管理扩展 C 盘分区。

电脑越来越卡顿如何解决？

先查占用：任务管理器里 CPU、内存、磁盘占用率高的进程；再清理开机启动项、关闭后台自启软件；检查磁盘剩余空间与健康度；硬件较旧时可考虑加内存或换固态硬盘，提升最明显。
